🛒 Shopping Cart System - Implementation Examples

Complete examples of how to integrate the cart system in your Laravel Blade templates.

Example 1: Quick Add Button (Catalog)

Single button that adds 1 item to cart with loading state.

Blade Code:

<div x-data="{ adding: false }">
    <button 
        @click="
            adding = true;
            fetch('{{ route('cart.add') }}', {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                    'X-CSRF-TOKEN': '{{ csrf_token() }}'
                },
                body: JSON.stringify({
                    product_id: {{ $producto->id }},
                    name: '{{ addslashes($producto->nombre) }}',
                    price: {{ $producto->precio }},
                    image: '{{ $producto->imagen }}',
                    quantity: 1
                })
            })
            .then(res => res.json())
            .then(data => {
                adding = false;
                window.dispatchEvent(new CustomEvent('cart-updated', { 
                    detail: data.cart 
                }));
                alert('✓ Producto agregado');
            })
            .catch(err => {
                adding = false;
                alert('Error');
            });
        "
        :disabled="adding"
    >
        <span x-text="adding ? 'Agregando...' : 'Agregar'"></span>
    </button>
</div>

Example 2: Add with Quantity Selector

Allows user to select quantity before adding.

Blade Code:

<div x-data="{ qty: 1, adding: false }">
    <!-- Quantity Selector -->
    <div class="flex gap-3">
        <button @click="if(qty > 1) qty--">-</button>
        <input type="number" x-model="qty" min="1">
        <button @click="qty++">+</button>
    </div>
    
    <!-- Add Button -->
    <button 
        @click="/* same fetch as Example 1, but use qty variable */"
        :disabled="adding"
    >
        <span x-text="adding ? 'Agregando...' : 'Agregar al carrito'"></span>
    </button>
</div>

Example 3: Cart Count Badge (Header)

Shows number of items in cart, updates automatically.

Blade Code:

<div x-data="{ 
    cartCount: 0,
    init() {
        // Load initial count
        fetch('{{ route('cart.count') }}')
            .then(res => res.json())
            .then(data => this.cartCount = data.count);
        
        // Listen for updates
        window.addEventListener('cart-updated', (e) => {
            this.cartCount = e.detail.total_count;
        });
    }
}">
    <a href="/cart">
        🛒 Carrito
        <span 
            x-show="cartCount > 0"
            x-text="cartCount"
            class="badge"
        ></span>
    </a>
</div>

Example 5: Update or Remove Cart Item

Update Quantity:

// Update item quantity
fetch('/cart/update/123', {
    method: 'PUT',
    headers: {
        'Content-Type': 'application/json',
        'X-CSRF-TOKEN': csrfToken
    },
    body: JSON.stringify({ quantity: 3 })
})
.then(res => res.json())
.then(data => {
    console.log('Updated cart:', data.cart);
});

Remove Item:

// Remove item from cart
fetch('/cart/remove/123', {
    method: 'DELETE',
    headers: {
        'X-CSRF-TOKEN': csrfToken
    }
})
.then(res => res.json())
.then(data => {
    console.log('Item removed, cart:', data.cart);
});

Clear Cart:

// Clear entire cart
fetch('/cart/clear', {
    method: 'DELETE',
    headers: {
        'X-CSRF-TOKEN': csrfToken
    }
})
.then(res => res.json())
.then(data => {
    console.log('Cart cleared');
});

📚 API Reference

Endpoint Method Description
/cart GET Get cart summary
/cart/add POST Add item to cart
/cart/update/{id} PUT Update item quantity
/cart/remove/{id} DELETE Remove item
/cart/clear DELETE Clear entire cart
/cart/count GET Get total items count
